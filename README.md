# Schreibfuchs

Lernwörter-App für Klasse 2 auf dem iPad, mit Apple Pencil oder Finger. Web-App ohne Server, ohne Konto, ohne Tracking. Läuft über GitHub Pages und vom Home-Bildschirm.

**Stand:** App 0.1 (Meilenstein M1): Wochen anlegen (von Hand oder per Foto über Claude), Wortkarten mit Silbenbögen und Silbenkönigen, Stationen „Silben schwingen“ und „Silbenkönige“, Elternbereich. Der Werkstatt-Test (Stift, Lineatur, Nachspuren, Scribble) liegt unter `werkstatt.html`.

## Testen auf dem iPad

1. Adresse in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
2. Über das Icon starten. Beim ersten Start legen die Eltern das Kind an, dann wählt das Kind sein Thema.
3. Nach jedem Update die App einmal ganz schließen und zweimal öffnen.
