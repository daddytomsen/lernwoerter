# Schreibfuchs

Lernwörter-App für Klasse 2 auf dem iPad, mit Apple Pencil oder Finger. Web-App ohne Server, ohne Konto, ohne Tracking. Läuft über GitHub Pages und vom Home-Bildschirm.

**Stand:** Meilenstein M0, Werkstatt-Test (Schreibfläche, Lineatur, Nachspur-Bewertung, Scribble-Prüfung). Die eigentliche App folgt ab M1.

## Testen auf dem iPad

1. Adresse in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
2. Über das Icon starten und die fünf Reiter der Reihe nach ausprobieren.
3. Unter „Bericht“ auf „Bericht kopieren“ tippen und den Text weitergeben.
